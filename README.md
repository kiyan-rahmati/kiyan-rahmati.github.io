# Kiyan Rahmati — Personal Portfolio

A modern, responsive and bilingual personal portfolio website for **Kiyan Rahmati**, a Web Developer focused on Frontend and Backend Development.

🌐 **Live Website:**  
https://kiyan-rahmati.github.io/

💻 **GitHub:**  
https://github.com/kiyan-rahmati

---

## ✨ Features

- 🌐 Persian / English language support
- 🌙 Dark / Light theme
- 📱 Fully responsive design
- 🔎 Global search with `Ctrl + K`
- 🚀 GitHub API integration
- 📂 Automatic project loading from public GitHub repositories
- 📝 Articles section
- 💬 Testimonials section
- 📩 Contact / collaboration section
- ⚡ Modern loading screen
- 🎨 Clean navy and purple visual design
- ♿ Accessible buttons, labels and navigation
- 🔗 GitHub project links and live demo links
- 📄 Custom 404 page
- 🔍 Basic SEO configuration
